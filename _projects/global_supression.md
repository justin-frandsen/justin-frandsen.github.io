This project investigates how the visual system learns to suppress task-irrelevant features, even when multiple distractors compete for attention.

In collaboration with **Brad Stilwell**, we examine:

- Whether suppression mechanisms operate independently across distractor types  
- How statistical learning shapes suppression efficiency  
- How suppression generalizes across contexts
