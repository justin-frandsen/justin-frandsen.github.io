This project applies **GBVS saliency modeling** and **image segmentation** to understand how fire attracts visual attention in primates raised without exposure to fire.

In collaboration with the **Yorzinski Lab**, we explore:

- Whether fire triggers innate attentional responses  
- How visual saliency interacts with learned relevance  
- How primates prioritize threat-related image features
